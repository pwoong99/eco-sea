# 웅이 박사 그림 넣는 곳

이 폴더에 아래 이름으로 PNG 파일을 올리면 게임이 자동으로 그림을 사용합니다.
파일이 없으면 코드로 그린 웅이 박사가 나옵니다.

| 파일 이름 | 쓰이는 장면 |
|---|---|
| `woong.png` | 기본 (브리핑 설명, 별명 정하기) |
| `woong_worry.png` | 걱정 (첫 브리핑, 보고 점검, 잠수정 고장) |
| `woong_happy.png` | 기쁨 (바다 정화 완료, 결과 발표) |

- 배경이 투명한 PNG, 세로로 긴 전신 그림(가로:세로 = 1:2 정도)이 가장 잘 맞습니다.
- `woong_worry.png`, `woong_happy.png`가 없으면 `woong.png`를 대신 씁니다.
